# Source 04 — W3C: WCAG 2.2

- URL: https://www.w3.org/TR/WCAG22/
- Type: Web accessibility standard
- Publisher: W3C
- Accessed: 2026-09-22
- Scores: credibility 5/5, recency 5/5, bias 5/5

## Relevant evidence

WCAG 2.2 adds minimum target-size and focus requirements relevant to service-navigation rows. It also requires meaningful relationships and sequence to survive presentation changes.

Short excerpt: “The size of the target for pointer inputs is at least 24 by 24 CSS pixels”

## Design implication

Make linked service rows large pointer targets, preserve DOM order on responsive layouts, and provide a visible inset focus ring.
