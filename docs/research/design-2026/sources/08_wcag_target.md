# Source 08 — WCAG 2.2 Target Size Minimum, W3C

- Type: primary accessibility standard guidance
- URL: https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html
- Reviewed: 2026-09-26

## Verbatim excerpts

> “Ensure targets meet a minimum size or have sufficient spacing around them.”

> “The size of the target for pointer inputs is at least 24 by 24 CSS pixels ...”

## Interpretation

The existing 48px token is a good internal standard for primary controls. Keep it for buttons, nav controls, and form inputs; do not shrink controls merely to achieve a denser “premium” look.
