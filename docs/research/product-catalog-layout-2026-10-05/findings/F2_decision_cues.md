# F2 — Product cards should answer four buyer questions

Each product item should make these questions easy to answer:

1. Is this close to my work?
2. Is it available or still being validated?
3. What does it help me do?
4. What is my next step?

The implementation maps these to category/tagline, launch status, description/feature teasers, price signal, and a single detail CTA. This follows the local product context and competitor product-story patterns (sources 02, 06, 08).
