# Source 06 — Orion Software product index pattern

- Type: primary / public product-studio evidence
- URL: https://www.orionsoftware.co/work
- Reviewed: 2026-10-05

## Evidence

Orion describes its work as product strategy, design, and engineering, then organizes the page around product stories with status, platforms, category, and short descriptions.

## Short quote

> “Products with a point of view.”

## Interpretation

The product index is more useful when each item has a point of view and status, rather than only a name and generic description.
