# Source 10 — GOV.UK Design System header

- Type: primary design-system reference
- URL: https://design-system.service.gov.uk/components/header/
- Reviewed: 2026-09-26

## Verbatim excerpts

> “The GOV.UK header component tells users they’re using a service on GOV.UK and lets them use GOV.UK-wide tools.”

The reference exposes a deliberately small, named set of navigation and accessibility components: header, service navigation, breadcrumbs, skip link, footer, pagination, details, and error summary.

## Interpretation

The useful lesson is not to copy GOV.UK’s visual identity. It is to design a small, predictable system of named primitives and keep site chrome quieter than the task content.
