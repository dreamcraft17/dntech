# DN Tech SEO and Market Audit Research

## Synthesis

The implementation has a solid SEO foundation: centralized metadata helpers, public JSON-LD builders, sitemap and robots routes, and a structured homepage. The most material unresolved risk is deployment configuration, not missing SEO primitives. The site must make the production host explicit and verify output after deployment.

Homepage on-page quality is good but not finished: the title is one character above the local checker heuristic and the rendered description is too short. The hero background uses an empty alt intentionally, which is correct for decorative imagery and should not be “fixed” with keyword text.

Market-wise, DN Tech should focus SEO and sales content around concrete buying situations rather than a broad custom-development promise. The segment model identifies three targets for validation: startup product engineering, complex multi-branch workflow, and legacy integration/modernization. UMKM remains a viable scoped segment, while generic price-led demand is a watch segment.

## Adversarial review

- A static build can pass while production returns wrong canonical URLs; live HTTP/GSC validation is mandatory.
- A 79/100 homepage score is not a ranking score and contains no authority or real-user performance data.
- Segment scoring can rationalize existing beliefs; interview/lead/win-loss evidence must update the scores.
- Adding more landing pages without unique content can create thin or doorway-like pages; publish only validated intents.
