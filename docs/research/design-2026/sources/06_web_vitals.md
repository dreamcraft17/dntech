# Source 06 — Web Vitals, web.dev

- Type: primary technical guidance
- URL: https://web.dev/articles/vitals
- Reviewed: 2026-09-26

## Verbatim excerpts

> “To provide a good user experience, LCP should occur within 2.5 seconds ... INP of 200 milliseconds or less ... CLS of 0.1 or less.”

> “A good threshold to measure is the 75th percentile of page loads, segmented across mobile and desktop devices.”

> “Only field measurement can accurately capture the complete picture.”

## Interpretation

The design brief should set measurable performance gates and use real-user data after launch. Hero imagery, chat, analytics, and animation need to earn their cost.
