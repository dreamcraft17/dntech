# Refresh targets

Review monthly or after a meaningful launch:

- Qualified conversations by buying job: MVP/product, workflow/integration, product evaluation.
- Homepage and template CTA conversion by route and source.
- Form start → qualified submission → converted lead by job.
- Product demo/try usage and product-page engagement.
- Search Console queries and landing pages for the three jobs.
- Core Web Vitals p75 for mobile and desktop; especially LCP, INP, CLS on hero-heavy pages.
- New case studies, product status, pricing, testimonials, and external proof.
- Navigation task success: find service, product, proof, contact, and process without search.
- AI-slop triggers: generic imagery, unsupported claims, duplicated copy, excessive animation, and “AI-powered” language without a concrete user benefit.

## Update triggers

- A new first-party product launches or changes readiness status.
- The top qualified audience changes based on CRM data.
- Search queries reveal a new high-intent job.
- A performance or accessibility gate regresses.
- A redesign experiment produces a statistically or operationally meaningful result.
