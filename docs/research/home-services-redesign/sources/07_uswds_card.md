# Source 07 — USWDS: Card

- URL: https://designsystem.digital.gov/components/card/
- Type: Government design-system guidance
- Publisher: U.S. Web Design System
- Accessed: 2026-10-02
- Scores: credibility 5/5, recency 5/5, bias 5/5

## Relevant evidence

USWDS describes cards as suitable for content about a single subject and notes
that cards work well with grid utilities.

## Design implication

Each service remains one subject and one destination. The layout uses a grid, but
varies the first card's visual weight so the section is not a repetitive matrix.
