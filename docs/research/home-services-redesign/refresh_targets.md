# Refresh Targets

Review after 30 days of production traffic or when the service catalog changes materially.

- Homepage service-row click-through rate.
- Click distribution by service name and viewport class.
- Scroll depth from services into process and advantages sections.
- Whether API descriptions exceed three readable lines on common mobile widths.
- Keyboard focus and contrast results after any token change.
- User wording from contact-form leads: website, app, integration, or operational problem.
