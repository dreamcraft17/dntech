# Source 04 — Site names in Google Search

- URL: https://developers.google.com/search/docs/appearance/site-names
- Type: Google Search Central, primary
- Used for: entity consistency and WebSite schema

Key notes: Google considers WebSite structured data along with homepage text, title, headings, and `og:site_name` when generating site names.
