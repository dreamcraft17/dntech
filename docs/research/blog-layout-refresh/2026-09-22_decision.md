# Blog layout refresh — decision brief

## Finding

The current page already has a sound reading width and sanitized article HTML, but its strongest visual treatment is still a single large card. The refresh should make the article feel like an editorial document: a clear hero, strong cover image, visible reading metadata, scannable sections, and a deliberate next step.

## Research synthesis

- Readability needs a constrained measure rather than full-width text.
- Web readers scan; headings, lists, and a concise lead should carry the first pass.
- A table of contents is useful when the document has multiple subsections and should link to the actual heading hierarchy.

## Adversarial check

- More UI can distract from reading. Therefore the TOC is conditional and secondary on mobile.
- A decorative hero can look like a marketing page. Therefore the visual system uses solid surfaces, borders, and editorial spacing instead of glass or ornamental gradients.
- A cover image may be missing. Therefore the layout has a neutral fallback panel and does not reserve an unexplained blank block.
